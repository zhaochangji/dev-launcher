w2 代理场景 —— 同名规则集覆盖，一次只能启用一套，切换即互斥

⚠️ 一次性配置引导（首次使用请先做这几步，做一次管很久）
  1. 浏览器代理：安装 Zero Omega 插件 → 新建情景模式 → 代理服务器 HTTP/HTTPS 都填 127.0.0.1:8899 → 切换到该模式。
  2. 信任 w2 根证书（w2 运行时）：打开 http://127.0.0.1:8899/ 下载根证书 → 双击导入「系统」钥匙串 → 右键显示简介 → 信任设为「始终信任」→ w2 restart。
  3. led 隧道登录（仅短剧项目需要）：终端 led login 浏览器完成 SSO。
  4. passport 白名单（仅短剧项目需要）：上面的 passport 链接申请 3 项（回调 / refer 域名 / sid，sid 填 kuaishou.kp.content），都填 led 域名。
  5. 访问纪律：staging 项目一律走 staging 域名（卡片上的「访问」按钮），不要用自动弹出的 localhost 页面登录（会被判 production）。
